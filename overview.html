01 The problem

Coverage is assumed. It is almost never proven.

Every security program runs on a comfortable assumption: the detections are working. That assumption holds right up until the one moment it needs to be true.

//A broken detection is invisible

A rule that silently stopped matching looks exactly like a quiet network. There is no alert for the alert that never fired.

//Coverage drifts the day you deploy

Log sources change, fields rename, a SIEM upgrade ships, someone edits a rule. Coverage decays continuously, and no one is watching the decay.

//Red teams are a snapshot

Point-in-time, narrow, and expensive, then stale the moment a rule changes. You can't run one every time an engineer merges a detection.

//You find the gap in the post-mortem

The blind spot gets discovered during the incident review, when the adversary has already used it. That is the most expensive possible time to learn it.
